# MailWatch P2

Sistema de análisis y monitoreo de correos.

## Tecnologías

### Frontend
- Electron
- React
- TypeScript

### Backend
- FastAPI
- Python

### Motor de análisis
- Python

### Base de datos
- PostgreSQL

## Registro de usuario (US-13)

Permite crear una cuenta desde la pantalla de acceso y rechaza correos duplicados.
Ver [instalación, API y pruebas](docs/US-13.md).
